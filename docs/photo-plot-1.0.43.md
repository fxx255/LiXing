# 1.0.43 照片与绘图增强

## 照片

拍题裁剪、助手大图、打卡与饮食照片预览均可顺时针旋转 90°。裁剪中的旋转暂存在预览内，取消不会修改文件；“保存裁剪”保存旋转后的裁剪范围，“使用整张”保存旋转后的完整图像。预览旋转直接保存本机照片，并刷新缩略图。

共享照片处理读取 EXIF 的方向和镜像信息，预览与保存使用相同坐标。写入同目录临时文件后原子替换，写入失败保留原图。PNG 保持无损 PNG，JPEG 以质量 100 保存，写回后像素已转正，不再沿用旧方向标签。

## 绘图协议

在原有 plots 协议上向后兼容扩展：

- `series.style`：`line`、`dashed`、`dotted`、`dashdot`、`marker`、`line_marker`。
- `series.colorIndex`：0 至 11，依次为蓝、金、绿、粉、紫、橙、青、黄绿、棕、红、浅蓝、灰；省略时按序列顺序自动分色。也可设置 `color:"#RRGGBB"`。
- `series.width`：0.75 至 5；`opacity`：0.05 至 1。
- `series.markerShape`：`circle`、`open_circle`、`square`、`diamond`、`triangle`、`cross`；`markerSize`：2 至 8。
- `markAreas`：保留原 x0/x1 带状区域，可增加 y0/y1 限定纵向范围，以及 colorIndex/color/opacity/pattern。
- 新增 `shades` 数组：每图最多 12 项，支持 `x0/x1 + upper/lower` 表达式曲边区域，或至少三个 `points` 顶点组成的多边形。`lower` 省略时为 0。两边界使用既有白名单表达式求值器，不能执行脚本。
- `shades.pattern`：`solid`（半透明填充）、`hatched`（斜线）、`crosshatch`（交叉斜线）。透明度限制在 0.03 至 0.6。

例：在 x∈[0,1] 内标记 y=x 和 y=x² 之间的区域：

```json
{
  "series": [{"expr":"x","label":"y=x"}, {"expr":"x^2","label":"y=x²"}],
  "shades": [{"x0":0,"x1":1,"upper":"x","lower":"x^2","colorIndex":6,"opacity":0.2,"pattern":"hatched"}]
}
```

绘制顺序为填充、网格与坐标轴、标记线、曲线、数据点。坐标轴上的点不再被轴线覆盖，边界点留出半径空间完整显示。填充限制在绘图区，表达式的无效值和明显极点跳变断开区域；坏的阴影参数只跳过该区域，不丢弃整张图和回答。

助手提示词同步说明新参数及用途，保留此前的峰谷、零基线、符号刻度、正文插图和图像比例规则。已有对话图片是保存的 PNG，需重新生成图像才能使用新增样式。

## 验证

新测试覆盖照片 EXIF 校正、旋转取消、旋转裁剪坐标、四次旋转、协议容错、颜色线型、图层先后、曲边区域面积及极点断开。设备测试在 MuMu模拟器12-1 上用真实 Canvas 校验轴上点的颜色和旋转后照片像素，并导出区域阴影与线型示例。最终测试数量和发布结果记录于 `docs/release-1.0.43.md`。
