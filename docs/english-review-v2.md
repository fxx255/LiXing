# 英语积累与背诵：第一、二阶段实现

本功能纳入 1.0.43；最终发布状态和正式包信息以该版本的发布记录为准。

## 使用方式

- 设置 → 英语背诵：可关闭背诵、调整每日新学上限、评分震动、自动朗读及英美发音。关闭后保留词条和记忆记录；每日上限为 0 时只复习旧词。
- 英语积累的新增、编辑窗口支持“填入免费词典释义”，填入后仍可修改自己的释义。
- 背诵先回忆，再点“查看释义”。展开前隐藏浮动圆钮与底部评分按钮。
- 展开后，圆钮点击播放发音，上滑“认识”、右滑“模糊”、下滑“忘记”。长按后拖动用于调整位置，不会评分；位置会保存，并限制在页面可操作区域内。
- 每次成功评分轻震一次；底部也有三个评分按钮，并显示预计复习间隔。误操作可以撤销本轮最近一次评分。
- 支持词典释义、词性、音标、词形、例句及译文、例句单词高亮、来源说明和记忆历史。长内容独立滚动。

## 免费内容来源

词库随安装包提供，普通查询不联网、不调用 AI，也不需要 API Key。此版本包含 156,321 个词条，其中 8,696 个词条有双语例句，压缩资源约 13.7 MB。

- ECDICT：中文释义、音标、词形；MIT 许可。
- WordNet 3.0：英文释义及含目标词或其变形的例句；随包保留 WordNet 许可。
- Tatoeba / ManyThings 英中句对：双语例句；CC BY 2.0，保留句子原文、作者归属及来源链接。
- 发音：Android 系统已安装的离线英文 TTS；未安装英文语音时给出提示，不影响背诵。
- 可选 Free Dictionary API：默认关闭，开启后仍需主动点击补充，只发送当前拼写，结果存本地缓存。外部服务可用性不由本应用保证。

没有使用付费牛津接口。离线数据不能保证每个词都有双语例句，也不会自动编造缺失的例句。词库筛选常见、考试词汇和部分常用短语，查询支持大小写规范化及部分变形回查。

词库构建脚本为 `scripts/build_free_dictionary.py`，输入位于忽略提交的 `build/english-sources/`：

- `ecdict.csv`：https://raw.githubusercontent.com/skywind3000/ECDICT/master/ecdict.csv
- `ECDICT-LICENSE.txt`：ECDICT 项目的 LICENSE。
- `wordnet.zip`：https://raw.githubusercontent.com/nltk/nltk_data/gh-pages/packages/corpora/wordnet.zip
- `cmn-eng.zip`：https://www.manythings.org/anki/cmn-eng.zip
- `fsrs.js`：https://raw.githubusercontent.com/open-spaced-repetition/fsrs4anki/main/fsrs4anki_scheduler.js
- `FSRS-LICENSE.txt`：FSRS4Anki 项目的 LICENSE。

运行 `python scripts/build_free_dictionary.py` 生成资源、许可与 `manifest.json`。发布资源的输入 SHA-256 和数据库 SHA-256 均记录在 manifest 中。压缩资源采用 `.db.pack` 扩展名，防止 Android 资源打包自动处理 `.gz`；首次查询在后台解压并校验，缓存文件名包含内容散列以区分更新后的词库。

## 记忆和数据

- 使用 FSRS-6 默认权重、90% 目标保持率，持久化稳定性、难度、学习阶段、首次学习时间、复习次数、遗忘次数、下次到期时间和每次评分历史。
- 学习步骤是本应用的明确规则：忘记后 1 分钟重学；新词/重学词选择模糊后 10 分钟重学；认识进入按记忆状态计算的天级间隔。成熟词选择模糊也按 FSRS 调整。默认权重尚不包含用户专属参数训练。
- 新词额度按用户设置的每日开始时间计数；到期旧词不受新词额度限制。在重学等待页到期后自动继续，退出也保留进度。
- 数据库从 12 升至 13，采用增量迁移；保留旧复习到期时间，在后续真实评分时转换原有记忆状态。
- 评分与历史在同一事务写入，事件 ID 防止重复评分，编辑释义保留最新记忆状态。
- 版本备份包含个人词条、记忆历史及相关设置；可重建的联网词典缓存不进入备份。
- WebDAV 同步包含评分事件；不同设备的独立记录按时间和事件 ID 确定顺序重算记忆。数据库版本不同的设备会停止互相导入并提示更新；多设备均需升级后再同步。

## 验证与限制

- 单元测试 598 项全部通过，覆盖调度、每日额度、评分去重、撤销、旧库迁移、词库读取、备份恢复、同步合并及手势冲突。
- `assembleDebug` 与 `lintDebug` 通过。静态检查发现原设置定位函数缺少就地权限判断，已补充判断。
- 仅在用户指定的 MuMu模拟器12-1 上操作，保留安装前数据备份。已验证展开前按钮隐藏、展开后的离线词典、长内容滚动、上/右/下滑评分、长按移动不评分、撤销、重开后位置与进度保留、词典释义填入、关闭背诵后隐藏入口并保留积累。
- 模拟器没有配置英文 TTS，未验证实际音频；模拟器不能替代真机震感验证。
- 开发测试包：`app/build/outputs/apk/debug/app-debug.apk`。正式分发采用同签名的 ARM64 release 包；版本信息见 1.0.43 发布记录。
