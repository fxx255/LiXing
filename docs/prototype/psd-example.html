例：题 3.3 的功率谱图

白噪声经「双带通滤波器 → 微分器」后的同相 / 正交分量功率谱。三张图都是按解析式真实算出来再渲染的， 不是手绘示意图。参数归一化取 f_c = 5、B = 2、N₀ = 1。

3.3 Y(t) 是平稳白噪声 n(t) 通过图 (a) 所示电路的输出，滤波器的传递函数 H(f) 如图 (b) 所示， 求 Y(t) 的同相分量及正交分量的功率谱密度，并画出功率谱图形。

思路：先把功率谱从输入推到输出，再做窄带搬移。

  1. 白噪声双边谱为 $$S_n(f)=N_0/2$$，经 H(f) 与微分器（$$H_d(f)=j2\pi f$$）后：$$S_Y(f)=\frac{N_0}{2}\,|H(f)|^2\,(2\pi f)^2$$
  2. Y(t) 是中心在 ±f_c 的窄带过程，同相/正交分量由频谱搬移得到：$$S_c(f)=S_s(f)=S_Y(f+f_c)+S_Y(f-f_c),\quad |f|\le B/2$$
图 1 · H(f) 幅频特性（题给条件：中心 ±f_c、带宽 B 的双带通）
图 2 · 输出 Y(t) 的功率谱 SY(f)：带内是 ∝f² 的抛物线，被 H(f) 限制在 ±f_c 两侧
结论
$$S_c(f)=S_s(f)=4\pi^2N_0\left(f_c^2+f^2\right),\quad |f|\le B/2$$
因双带通的上下两个边带各自搬移一次，幅度叠加为两倍。窄带近似（f_c ≫ B/2）下可视为高度 $$4\pi^2N_0f_c^2$$ 的矩形。
图 3 · 同相分量与正交分量的功率谱（两条曲线完全重合：Sc(f) = Ss(f)）

注意图 3 并非严格矩形——本题 f_c/B = 2.5，窄带条件并不极端，谱在带内随 f² 略微上翘 （边缘比中心高约 4%）。只有当 f_c ≫ B/2 时才退化为矩形。
