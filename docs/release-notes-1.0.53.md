# 砺行 1.0.53

- 修复多设备同步时旧打卡进度覆盖新记录的问题；同步后按实际任务重新计算当日完成度和相关统计。
- 新日期的计划完成度考虑预计学习时长和任务实际完成比例，历史日期沿用原口径。
- 助手为新对话生成概括标题，图片提问的历史记录更容易辨认。
- 计划页默认收起学习资料与目标；每日安排按天查看和编辑，可逐日切换或用日历选日期。
- 助手重发入口位于失败消息旁；切换服务商后可用当前服务商重发原问题。

多设备使用时，请将各设备都升级到此版本。本版包名为 `com.example.lixing.debug`，versionCode 54，minSdk 26，仅发布 ARM64 包。
