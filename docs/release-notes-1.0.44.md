砺行 1.0.44

- 修复部分长公式无法显示的问题，保持原公式内容。
- 助手新增可放大查看的通信框图，支持调制、相干解调、包络检波等常见结构。
- 图文混排在自动续写和备份恢复后保持正确顺序，未指定插图位置的图会显示在文末。
- 助手正文逐步显示，思考内容与正式回答分离；保留原有自动续写、图片和方案确认功能。
- 中断后可从输入框左侧重新发送，复用原问题与回答位置；重新打开应用不会自动重发。
- 固定问题与回答占位的先后顺序，避免同时写入时重开会话出现顺序颠倒。
- 生成任务由应用统一管理，切页后仍可继续；重新打开会话可恢复正文、图片与待确认方案。系统强制停止后的任务可手动重试。
- 按会话保存未发送的文字和照片，保护切换会话或重试期间的新草稿。
- 调整请求中稳定内容与动态学习数据的顺序，改善缓存复用条件；缓存统计按服务商实际返回数据计算，不保证固定命中率或响应速度。

- 修复坚果云同步遗漏历史计划、模板和打卡的问题；升级后首次同步重新核对以前可能漏收的记录。
- 修复两台设备同一天同一任务编号不同而无法合并的问题，保留打卡、专注、积分关联及本机照片。
- 修复本地改动未上传、导入失败后不再重试、第三台设备转发导致冲突结果变化的问题。
- 应用前台每两分钟拉取对端改动，回到前台也会检查；失败自动重试，遵守自动同步与仅 Wi-Fi 设置。
- 显示发现的其他设备数量和失败原因，仅完整成功时更新同步时间；修复餐食、活动计划和备份恢复的相关问题。

请将所有设备更新至 1.0.44，并确认使用相同的坚果云账号和目录。更新后可在主设备、另一台设备、主设备依次点击“立即同步”完成一次往返核对；首次核对可能稍久，无需清空云端文件。照片文件仍不参与日常增量同步。

历史对话中已经保存的 PNG 不会自动重绘；如需使用新的绘图效果，请让助手重新生成。
