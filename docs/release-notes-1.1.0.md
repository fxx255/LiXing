# 砺行 1.1.0

- 英语背诵的“模糊”评分改为左滑，保留上滑认识、下滑忘记和长按移动；悬浮按钮改为深灰底、上绿左黄下橙的三段圆环。
- 单词和短语默认优先使用有道词典的免费英美发音，无需 API Key；首次联网只发送当前单词或短语，音频缓存在本机。可在设置中关闭，网络失败时回退系统英文语音；例句继续使用系统离线语音，并优先选择对应口音的高音质语音包。
- AI 模型配置支持填写上下文窗口，提供 32k～1M tokens 常用选项和自定义窗口；配置后按完整请求的估算预算裁剪最早历史，当前问题及续写原问题保留，窗口不足时明确提示。
- 助手输入区增加上下文占用圆环，区分估算与接口上报用量，随回复更新；本次用量随请求保存，切换会话后显示对应记录。

包名为 `com.example.lixing.debug`，versionCode 56，minSdk 26，仅发布 ARM64 正式包；沿用原签名，可覆盖安装。数据库版本不变。上下文 token 数为估算或接口上报值，不能扩大服务端真实窗口。
